# File XOR Processor (Qt / C++)

Многопоточное десктопное приложение для бинарной модификации файлов операцией XOR с 64-битным ключом.

## Стек технологий
* **C++17**
* **Qt 6 **
* **Сборочная система:** CMake
* **Компилятор:** MinGW 64-bit

## Реализованные требования 
- [x] Поиск файлов по маске (`*.txt`, `*.bin` и т.д.).
- [x] Опциональное удаление исходных файлов после завершения.
- [x] Разрешение коллизий имен файлов (перезапись либо инкрементный счетчик `_1`, `_2`).
- [x] Разовый запуск или периодический опрос по таймеру с заданным интервалом.
- [x] Потоковая 8-байтная (64 бит) операция XOR с ключом из HEX-строки.
- [x] **Обработка файлов 10+ ГБ без блокировки GUI:** чтение и запись порциями по 4 МБ, константное потребление памяти (~20 МБ RAM).
- [x] **Пауза и возобновление:** синхронизация на `QMutex` + `QWaitCondition` между блоками без холостого цикла (0% CPU в паузе).
- [x] **Безопасное завершение работы:** корректная обработка `closeEvent` с ожиданием завершения потока и удалением незавершенных временных файлов.

## Архитектурные особенности
Логика ввода-вывода полностью изолирована от пользовательского интерфейса с использованием архитектурного паттерна **Worker-Thread** (`QObject::moveToThread`). Обмен данными и управление состоянием происходят исключительно через потокобезопасный механизм сигналов и слотов Qt.

## Сборка и запуск
1. Открыть `CMakeLists.txt` в **Qt Creator**.
2. Выбрать комплект сборки: **Desktop Qt 6.x.x MinGW 64-bit**.
3. Собрать проект (`Ctrl + B`) и запустить (`Ctrl + R`).
